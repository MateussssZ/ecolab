# Лабораторная работа №4: Реализация алгоритма Worst Fit для распределения памяти в Eco OS

## Цель работы

Исследование и реализация алгоритма динамического распределения памяти **Worst Fit (Наименее Подходящий)** для операционной системы Eco OS.

## Теоретическая часть

### Алгоритм Worst Fit

**Worst Fit** - это алгоритм динамического распределения памяти, который выбирает для размещения запроса **самый большой доступный свободный блок**.

#### Математическая формализация
Пусть:
F = {f₁, f₂, ..., fₙ} - множество свободных блоков размера sᵢ
R - размер запроса
H - размер заголовка блока

Алгоритм Worst Fit:

    1. Найти fⱼ ∈ F, такой что:
а) sⱼ ≥ R + H
б) sⱼ = max{sᵢ | sᵢ ≥ R + H, ∀fᵢ ∈ F}

    2. Если fⱼ существует:

Если sⱼ - R - H ≥ H + минимальный_размер_данных:
Разделить fⱼ на два блока:
fⱼ' размер R + H (занятый)
fₖ размер sⱼ - R - 2H (свободный)

Иначе:
Отдать весь блок fⱼ

    3. Иначе: Отказ в выделении


#### Визуализация простого примера

**Исходное состояние памяти:**

Блок A -> 100 В -> Свободен
Блок B -> 200 В -> Свободен
Блок C -> 300 В -> Свободен
Блок D -> 500 В -> Свободен


**Запрос на 150 байт:**

Доступные блоки:

A: 100 B (слишком мал)
B: 200 B (подходит) 
C: 300 B (подходит) 
D: 500 B (подходит) (этот блок будет выбран алгоритмом, т.к. он - самый большой)

Тогда блоки будут поделены следующим образом

Блок A -> 100 В -> Свободен
Блок B -> 200 В -> Свободен
Блок C -> 300 В -> Свободен
Блок D -> 150 В -> Занят
Блок Е -> 350 В -> Свободен

## Результаты 

Алгоритм Worst Fit успешно реализован и интегрирован в Eco OS. Все основные функции работают корректно:

* Выделение памяти: Алгоритм всегда выбирает самый большой доступный блок

* Освобождение памяти: Освобожденные блоки корректно объединяются с соседями

* Управление фрагментацией: Минимизируется внешняя фрагментация

* Обработка ошибок: Корректная обработка пограничных случаев

Алгоритм демонстрирует хорошую эффективность использования памяти за счет минимизации внешней фрагментации, что особенно важно во встраиваемых системах с ограниченными ресурсами. Недостатками данного алгоритма может считаться сложность O(n), что может быть узким горлышке при частой работе с мелкими массивами данных
